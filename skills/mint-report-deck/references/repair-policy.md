# V0.6 自动修复与阻断策略

自动修复的目标是恢复既有内容与布局合同，不是重新创作。每轮必须保存输入、输出、结构 diff 与 QA；最多两轮。

## 固定顺序

1. 删除支持区完全重复的文字，不删除 primary atom。
2. 使用 CJK 合同调整语义断行；标题需改写时停止，不由修复器改写事实。
3. 仅在已有 zone 中重分配空间；空支持区可删除并让主视觉扩展。
4. 重新选择与既有语义关系兼容的 Pattern；不得改变 relationType。
5. 只有页数合同允许且上游提供完整、互斥、覆盖全部 primary atom 的批准拆页计划时才拆页。
6. 仅允许不低于 90% 的有限字号缩放，且不得突破 CJK 与密度最低字号。

## 必须阻断

- 修改、删减或新增事实、实体、数字、primary atom、关系类型或证据。
- 并列关系带箭头、无证据因果、主语未知、内容冲突等语义错误。
- exact-one-page 要求下尝试拆页。
- 无兼容 Pattern、标题必须改写、两轮后仍失败。
- 仅靠隐藏警告、降低 QA 阈值或删除失败样例才能通过。

正式状态只有 `formal-ready`、`repair-required`、`blocked`。`repair-required` 不得导出正式版。
