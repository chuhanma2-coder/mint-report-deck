# 整份材料版式节奏合同

- 版式变化只能发生在语义、容量、证据、阅读轴和连接器硬约束均通过之后。
- 同一 Pattern 默认不得连续超过2页；第三页若没有兼容变体，必须记录 `rhythmException` 及候选淘汰依据。
- 10页及以上材料原则上至少覆盖4个 Pattern family：narrative、comparative、directional、structural、quantitative、decision、media。
- 三个及以上章节引言必须使用相同 `introFamily`、Pattern和阅读结构；章节内容页可以按各自语义变化。
- 节奏 QA 不因追求数量而把并列改成流程、把关系图改成装饰图或把精确数据改成不可核对的图形。
- 每页选择必须保留硬筛选结果、候选分数、最终理由及节奏例外；无解释的随机换版式视为失败。
