# Mint 中文 CJK 排版合同

## 标题合同

- 所有标题最多两行；每行不超过22个中文字符宽，总计不超过36。
- 第一行交代主体或前提，第二行给出动作、影响或结论。
- 优先在逗号、分号、冒号、顿号或前提与结论边界断行；不得以闭标点开行、以开标点结行，也不得出现单字孤行。
- 超过容量时必须先提炼页面命题或更换版式，禁止仅靠缩小字号通过。

## 不拆分语义单元

- 金额、百分比、数字与单位、英文缩写、产品名和模型名按一个阅读单元处理。
- 典型示例：`36,868个`、`58%`、`人民币5,000万元`、`DeepSeek V4 Pro`、`M-PESA`。
- HTML 使用 `.cjk-token { white-space: nowrap; }`；PPTX 生成器必须使用同一分词结果。

## 字体合同

- 无衬线中文：`Noto Sans SC` → `Source Han Sans SC` → `PingFang SC` → `Microsoft YaHei` → 通用无衬线。
- 衬线中文：`Noto Serif SC` → `Source Han Serif SC` → `Songti SC` → `SimSun` → 通用衬线。
- macOS 和 Windows 字体必须同时进入 CSS fallback；浏览器 QA 至少确认一个受控中文字体可用。

## 双重验收

- 编译前静态检查：行数、字符宽、禁则、保护单元、标题总长。
- 渲染后浏览器检查：实际行盒、溢出、最小字号、保护单元是否跨行、字体可用性。
- 任一检查失败，页面状态为 `repair-required` 或 `blocked`，不得作为正式版交付。
